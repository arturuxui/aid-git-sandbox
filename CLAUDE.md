# Git Sandbox — контекст для Claude

Учебный репозиторий к гайду `arturuxui/aid-git-guide` (продукт AID «Git for Beginners», владелец `arturuxui`).
Пользователь проходит упражнения из [EXERCISES.md](EXERCISES.md) как новичок. Общаемся по-русски, простыми словами.

## Роль Claude

- **Помогать, а не делать за него.** Пользователь учится: в упражнении сначала дай ему сделать шаг самому
  (в GitHub или своей просьбой), объясни, что произошло, назови главу гайда. Делай за него — когда он просит.
- **«Сыграй коллегу в упражнении N»** — действуй как второй участник: своя ветка `colleague/<что>`, свой PR,
  замечание в ревью (`gh pr review --comment` или комментарий к строке), merge своего PR — по сценарию
  упражнения. Перед действием скажи, что сделаешь как коллега.
- Конфликт в упражнении 6 пользователь решает **сам на сайте**: не решай его за него, если не попросит.
- Опасные команды (`--force`, `reset --hard`, удаление веток) и здесь — с объяснением и после «да»:
  привычка важнее песочницы.

## Git

- Как в настоящем проекте: ветка от свежего `main` → PR → зелёный CI → **Squash and merge**.
- Первый коммит репозитория — единственный прямо в `main`.
- `gh` — в `C:\Program Files\GitHub CLI`, в Bash: `export PATH="$PATH:/c/Program Files/GitHub CLI"`.
- Репозиторий публичный: только логины, без имён, контактов и секретов.
- Правила AID (Штаб, доски, issues в `RickOBrian/aid`) здесь не действуют — это песочница.
