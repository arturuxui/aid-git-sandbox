# Git Sandbox — учебный репозиторий

Песочница для упражнений гайда [Git for Beginners](https://github.com/arturuxui/aid-git-guide)
(продукт AID). Здесь отрабатывают ветки, коммиты, PR, ревью, CI, merge и конфликты.
Ничего отсюда не выкатывается.

- [EXERCISES.md](EXERCISES.md) — упражнения по главам.
- `button.css`, `card.css` — учебные файлы, которые правят в упражнениях.
- `.github/workflows/checks.yml` — учебные проверки: **Цвета** (в CSS только `var(--...)`, без HEX)
  и **Конфликты** (не осталось маркеров конфликта).
